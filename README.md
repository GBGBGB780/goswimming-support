## Publish with GitHub Pages

1. Sign in to GitHub as `gbgbgb780`.
2. Create a new **public** repository named `goswimming-support`.
3. Upload everything inside this folder to the repository root.
4. Commit the uploaded files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main`, folder `/(root)`, and save.
8. Wait for GitHub Pages deployment to finish.

Expected public URLs:

- Home: `https://gbgbgb780.github.io/goswimming-support/`
- App Support: `https://gbgbgb780.github.io/goswimming-support/support.html`
- Privacy Policy: `https://gbgbgb780.github.io/goswimming-support/privacy.html`

Use the Support and Privacy Policy URLs in App Store Connect.

## Files

- `index.html`: public landing page
- `support.html`: App Store support page and contact information
- `privacy.html`: bilingual privacy policy
- `styles.css`: responsive site styling
- `assets/app-icon.png`: Go Swimming icon

## Before Publishing

- Preview all pages in a browser.
- Verify the email links open correctly.
- Keep the privacy policy synchronized with the in-app privacy policy.
- Do not upload the main project's existing `docs` folder; it contains internal
  engineering and research documents that are not intended for the public site.
